1為什麼要用弧度制（Radians）？

角度（degree）是人為訂出的單位（把一個圓分成 360 份），而弧度（radian）是用「弧長 = 半徑」時所對應的角度來定義——這是一個跟圓的幾何本質直接掛鉤的單位。這也是為什麼所有微積分公式（例如 d/dx(sinθ) = cosθ）只有在弧度制下才成立：這些公式的推導過程用到 sinθ ≈ θ（當 θ 很小時）這個近似，而這個近似只有在弧度制下才精確。

弧度 = 角度 × (π / 180) 例如：180° = π rad，90° = π/2 rad，60° = π/3 rad
單位圓上標示常見角度的度數與弧度對照
⚠ 常見錯誤：在使用弧長公式 s = rθ 或扇形面積公式 A = ½r²θ 時，若題目給的是角度，必須先轉換成弧度才能代入，否則答案會錯一個 (180/π) 倍數。

2sin / cos 圖形的關鍵特徵

sinθ 和 cosθ 的圖形都是「週期為 2π」的波浪形，振幅（amplitude）都是 1（即最大值 1、最小值 −1）。兩者形狀完全相同，只是 cosθ 比 sinθ「提早」π/2 出現——也就是說 cosθ = sin(θ + π/2)。

sinθ（青色）與 cosθ（紫色）在 0 到 2π 之間的圖形比較

從圖中可以觀察到幾個關鍵座標點，這些是解三角方程時常用的「基準點」：

關鍵座標

sinθ：最大值在 θ=π/2（值=1），最小值在 θ=3π/2（值=−1），θ=0, π, 2π 時為 0 cosθ：最大值在 θ=0, 2π（值=1），最小值在 θ=π（值=−1），θ=π/2, 3π/2 時為 0

3Compound Angle 加法公式

這組公式讓我們可以把「兩個角相加或相減」的三角函數，拆解成單一角的三角函數組合。這是後面 double angle 和 R sin(θ+α) 技巧的基礎，務必理解推導邏輯，而不是死記。

sin(A ± B) = sinA cosB ± cosA sinB sin 展開式的正負號跟原式一致
cos(A ± B) = cosA cosB ∓ sinA sinB 注意：cos 展開式的正負號跟原式相反！
tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)
⚠ 常見錯誤：cos(A+B) 展開後中間是「減號」，cos(A−B) 展開後中間是「加號」——這跟 sin 的規律剛好相反，非常容易搞混，建議每次用之前先在草稿紙上寫一次公式確認。
例題

求 sin75° 的精確值（用 sin75° = sin(45°+30°)） sin(45°+30°) = sin45°cos30° + cos45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2) / 4

4Double Angle 二倍角公式

把 compound angle 公式中的 B 換成 A（即 A+A=2A），就能推導出二倍角公式。這正是「理解推導比死記更牢固」的最佳示範。

sin(2A) = 2 sinA cosA
cos(2A) = cos²A − sin²A = 2cos²A − 1 = 1 − 2sin²A 三個形式都要熟悉——考題常指定「用哪一個形式證明」
tan(2A) = 2tanA / (1 − tan²A)
例題

化簡：2sin(3x)cos(3x) 用 sin(2A)=2sinAcosA，令 A=3x： 2sin(3x)cos(3x) = sin(6x)

5R sin(θ+α)：建模的核心工具

這是整個 Trigonometry and Modelling 主題最重要的技巧。當我們遇到 a sinθ + b cosθ 這種「兩個三角函數相加」的表達式時，可以把它重寫成「單一個波浪」的形式 R sin(θ+α)——這樣就能直接看出振幅（amplitude）、最大/最小值、以及相位偏移（phase shift）。

推導邏輯

目標：a sinθ + b cosθ = R sin(θ+α)。先展開右邊：

R sin(θ+α) = R sinθ cosα + R cosθ sinα

比較係數：sinθ 的係數 a = R cosα；cosθ 的係數 b = R sinα。把這兩個方程平方相加：

a² + b² = R²cos²α + R²sin²α = R²(cos²α+sin²α) = R² 所以 R = √(a² + b²)

兩式相除消去 R：

tanα = b / a 務必檢查 (a,b) 所在象限，確保 α 落在正確範圍
y = 3sinθ + 4cosθ 與其等價形式 y = 5sin(θ+53.13°) 是同一條曲線——R 是振幅，α 是相位偏移

從圖中可以直接讀出兩個關鍵資訊：

如何讀圖

最大值 = R（圖中曲線的最高點） 最大值出現的位置：θ + α = 90°，即 θ = 90° − α （因為 sin 函數在輸入為 90° 時達到最大值 1，此時整個表達式等於 R×1 = R）

⚠ 常見錯誤：求「最大值出現的 θ」時，很多學生會直接寫 θ=90°，忘記減去 α——正確答案是 θ = 90° − α（或用弧度：θ = π/2 − α）。

6實際建模應用：潮汐高度模型

Modelling 題目通常會把 R sin(θ+α) 技巧套用在真實情境中，例如潮汐高度、摩天輪高度、日照時數變化等。這類題目的關鍵是：先把情境中給的函數化簡成 R sin(θ+α) 的形式，才能回答「最大值」「最小值」「何時發生」這類問題。

情境例題

某海灣的潮汐高度 h(t)（米），t 為從午夜開始的小時數，模型為： h(t) = 12 + 5sin(t) − 12cos(t)，0 ≤ t < 24 第一步：化簡 5sin(t) − 12cos(t) 為 R sin(t−α) 形式 R = √(5²+12²) = 13 tanα = 12/5 → α = 67.38° 所以 h(t) = 12 + 13sin(t − 67.38°) 第二步：回答問題 最大高度 = 12 + 13 = 25 米 發生在 t − 67.38° = 90°（換算成弧度或保持角度制需視題目單位），解得 t ≈ 2.74 小時，即凌晨約 2:44

潮汐高度 h(t) 在 24 小時內的變化，標示最高點、最低點與基準線（水平中線 = 12）
⚠ 常見錯誤：常數項（例子中的 12）不屬於振幅 R 的一部分，它只是把整條曲線垂直往上平移——很多學生誤把最大值算成「R」而忘記加回常數項。

📌 精要學習重點

  • 弧度制是一切的前提——所有標準三角函數微分公式只在弧度制下成立，做題前先確認單位。
  • Compound angle 公式的符號規則要背熟：sin 展開式符號不變，cos 展開式符號相反。
  • Double angle 有三種 cos(2A) 形式——依題目要求（例如要消去 sin² 還是 cos²）選擇正確形式，而不是隨便挑一個。
  • R sin(θ+α) 是整個主題的核心：R = √(a²+b²)，tanα = b/a（務必檢查象限）。看到「a sinθ + b cosθ」型式，第一反應就該是「轉換成 R sin(θ+α)」。
  • 最大值發生的位置要記得減去 α：θ = 90° − α，而不是直接等於 90°。
  • 建模題中的常數項（垂直平移）不算進振幅 R——最大值 = 常數 + R，最小值 = 常數 − R。
  • 與 Differentiation 的銜接：R sin(θ+α) 形式常常可以直接讀出最大/最小值，不需要真的做微分——考試中辨認出這個「捷徑」能省下大量時間。
  • 「Show that」題目一定要寫出每一步代數過程，不能只寫最終答案，method marks 是靠步驟拿的。
